# ヤンデレメイドの館からの脱出 - ローカルネットワーク対応Webアプリ 🩸🖤

文化祭やイベントのホラー謎解き企画で使用する、親機（サーバーダッシュボード）と子機（10台のプレイヤー端末）間でのリアルタイム通信システムです。

---

## 📁 ファイル構成

```text
.
├── app.py                  # Python Flask-SocketIO サーバー
├── questions.json          # 全10問の問題・選択肢・解説・メイド叱責メッセージデータ
├── titles.json             # 脱出結果（クリア／ゲームオーバー）の称号＆メイドコメント設定
├── templates/
│   ├── index.html          # 子機（プレイヤー）用ゲーム画面 UI/UX
│   └── admin.html          # 親機（ハッカー風監視モニター）ダッシュボード UI
├── static/
│   └── audio/              # 効果音・BGM格納用フォルダ（任意配置）
└── README.md               # 本ドキュメント
```

---

## 🚀 起動方法

### 1. 依存ライブラリのインストール
Python 3.8 以上がインストールされている環境で、以下のパッケージをインストールします。

```bash
pip install flask flask-socketio gevent
```

### 2. サーバーの起動
親機PC上で以下のコマンドを実行してサーバーを立ち上げます。

```bash
python app.py
```
起動すると `http://0.0.0.0:5000` で待機状態になります。

---

## 🌐 ローカルネットワーク（Wi-Fi / LAN）でのアクセス方法

1. 親機PCのローカルIPアドレスを確認します（例: `192.168.1.100`）。
   - Windows: `ipconfig`
   - Mac / Linux: `ifconfig` または `ip a`
2. **親機ダッシュボード（管理用）:**
   - Chrome等のブラウザで `http://localhost:5000/admin` （または `http://192.168.1.100:5000/admin`）を開きます。
3. **子機端末（プレイヤー10台）:**
   - 同一Wi-Fi / LANに接続した各PC/タブレットのブラウザから `http://192.168.1.100:5000/` へアクセスします。

## 🔊 音響ファイルの設定 (`static/audio/`)

音声ファイルは `static/audio/` ディレクトリ内に以下のファイル名で配置してください。
※ファイルが未配置の場合でも、Web Audio API Synth（電子合成音）のフォールバック機能が起動し、自動的に音響効果が再生されるため、そのまま動作確認が可能です。

- `heartbeat_slow.mp3`: 待機中の心臓の鼓動音
- `countdown.mp3`: カウントダウン時の効果音
- `bgm_horror.mp3`: プレイ中のBGM（通常時）
- `bgm_panic.mp3`: 残り30秒以下のパニックBGM
- `scream.mp3`: 誤答時の悲鳴・衝撃音
- `correct.mp3`: 正解時のサウンド

## ✨ 主な機能と特徴

### 1. 耐障害・レジリエンス（自動復旧機能）
- プレイヤーが誤ってブラウザをリロード（再読み込み）したり、通信が一瞬切断されたりしても、`localStorage` とサーバーの経過時間（タイムスタンプ）の同期により、**残り時間・現在の問題番号・間違えた回数（コンティニュー数）が瞬時に自動復旧**します。

### 2. 高度なホラーUI/UXデザイン
- 漆黒（`#0a0a0a`）、深紅（`#8b0000`）、ネオンレッド（`#ff1a1a`）を基調とした漆黒の配色。
- Google Fonts `Shippori Mincho` によるホラーフォント。
- 背景のTVノイズ・走査線（Scanline）、閉塞感を高めるビネット（Vignette）効果。
- 残り30秒未満になると画面周囲の血が脈打つパルスアニメーション。
- 誤答時の赤フラッシュ演出とメイドの叱責ダイアログ（「最初からやり直す (Q.1へ)」ボタンでコンティニュー数+1）。

### 3. ハッカー風親機ダッシュボード (`/admin`)
- 全10部屋の「待機中 / プレイ中 / 終了」ステータスをグリッド形式でリアルタイム表示。
- 各部屋の残り時間タイマー、プレイヤー名、間違えた回数、脱出コードが一目で分かります。
- 個別スタート／リセットおよび、一括スタート／一括強制リセットボタンを標準装備。
